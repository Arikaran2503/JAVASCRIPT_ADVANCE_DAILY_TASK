# Day 28 – JavaScript Advanced Daily Tasks

## Project Overview

This folder contains two JavaScript projects designed to apply programming concepts to practical, real-world situations. The tasks focus on expense sharing and mobile data usage management, helping improve logical thinking, calculation skills, and interactive web development.

## Technologies Used

- **HTML5** – Structures the application interface.
- **CSS3** – Styles the web pages.
- **JavaScript** – Handles calculations, user input, and application logic.

## Tasks Included

### Task 1: Group Trip Expense Splitter

**Folder:** `task1-Group-Trip-Expense-Splitter`

#### Project Description

The Group Trip Expense Splitter is a JavaScript-based application that helps a group of people calculate and divide shared trip expenses. Instead of manually calculating each person's contribution, users can enter the expense details and determine how much each person should pay.

#### Key Features

- Enter the total trip expenses.
- Specify the number of people participating in the trip.
- Calculate the expense share for each person.
- Display the calculated amount clearly.
- Simplify the process of sharing group expenses.

#### Concepts Practiced

- Variables and functions
- User input handling
- Arithmetic operations
- Form validation
- DOM manipulation
- Event handling

#### Learning Outcome

This task helps develop practical calculation skills and demonstrates how JavaScript can simplify everyday activities such as dividing travel expenses among friends.

### Task 2: Mobile Data Usage Tracker

**Folder:** `task2-Mobile-Data-Usage-Tracker`

#### Project Description

The Mobile Data Usage Tracker is a JavaScript-based application that helps users monitor their mobile data consumption. It allows users to enter their data allowance and usage details to calculate the remaining data balance.

#### Key Features

- Enter the available mobile data limit.
- Record the amount of data used.
- Calculate the remaining data balance.
- Display data usage information.
- Help users understand their consumption in relation to their data limit.

#### Concepts Practiced

- Variables and data types
- Functions
- User input handling
- Arithmetic calculations
- Conditional statements
- DOM manipulation
- Event handling

#### Learning Outcome

This task helps improve logical thinking and demonstrates how JavaScript can be used to calculate and display data usage information dynamically.

## How to Run the Projects

1. Open the required task folder.
2. Locate the `index.html` file.
3. Open the file in a web browser.
4. Enter the required information into the input fields.
5. Click the appropriate button to perform the calculation.
6. View the results displayed on the webpage.
