## Project Overview

The **Factorial Calculator** is a JavaScript-based web application that calculates the factorial of a number entered by the user. It uses JavaScript looping logic to multiply all positive integers from 1 up to the given number and displays the final result.

## What Is Factorial?

The factorial of a non-negative integer is the product of all positive integers from 1 to that number.

It is represented using the symbol `!`.

**Example:**

5! = 5 × 4 × 3 × 2 × 1 = 120

Other examples:

- 3! = 3 × 2 × 1 = 6
- 4! = 4 × 3 × 2 × 1 = 24
- 0! = 1

## How the Application Works

1. The user opens the Factorial Calculator application.
2. The user enters a number in the input field.
3. The user clicks the Calculate Factorial button.
4. JavaScript retrieves the entered number.
5. The program initializes a variable to store the factorial result.
6. A loop executes to multiply the numbers from 1 up to the entered number.
7. The final factorial value is calculated.
8. The result is displayed dynamically on the webpage.
