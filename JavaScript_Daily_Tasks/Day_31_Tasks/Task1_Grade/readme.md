# Task 1 – Grade Calculator

## Project Overview

The **Grade Calculator** is a JavaScript-based web application designed to calculate a student's grade based on the marks entered by the user. It accepts student marks, processes the values using JavaScript conditions, and displays the corresponding grade.

This project helps understand how conditional statements and logical operations can be used to develop a simple student grading system.

## Technologies Used

- **HTML5** – Used to create the structure of the application and input fields.
- **JavaScript** – Used to process marks, apply grading conditions, and display results.

## Project Structure

```text
Task1_Grade/
│
├── index.html
├── script.js
└── Output/
```

## Features

- Accepts student marks through an input field.
- Processes the entered marks using JavaScript.
- Checks the marks against the defined grading conditions.
- Calculates and displays the corresponding grade.
- Provides an interactive interface for grade calculation.
- Handles different mark ranges using conditional statements.
- Displays the result dynamically without manually calculating the grade.

## How the Application Works

1. The user opens the Grade Calculator application.
2. The user enters the student's marks in the input field.
3. The user clicks the Calculate Grade button.
4. JavaScript retrieves the entered marks.
5. The program checks the marks using conditional statements.
6. Based on the defined grading criteria, the appropriate grade is determined.
7. The final grade is displayed on the webpage.

## File Description

### 1. index.html
- Creates the basic structure of the Grade Calculator.
- Provides an input field to enter student marks.
- Includes a button to calculate the grade.
- Provides a section to display the result.
- Connects the JavaScript file to the webpage.

### 2. script.js
- Retrieves the marks entered by the user.
- Processes the input value.
- Uses conditional statements to check the mark range.
- Determines the appropriate grade.
- Displays the calculated result dynamically.
