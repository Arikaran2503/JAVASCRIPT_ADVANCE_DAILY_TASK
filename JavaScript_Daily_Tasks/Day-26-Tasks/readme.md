# Day 26 – JavaScript Daily Tasks

## Project Overview

This project contains two JavaScript applications that demonstrate practical problem-solving through appointment management and job application tracking.

## Technologies Used

- HTML5
- JavaScript

## Tasks Included

### Task 1: Appointment Scheduling System

**Folder:** `Task1-Appointment Scheduling System`

- Accepts appointment details from the user.
- Validates the entered appointment date and time.
- Checks for duplicate appointment times.
- Helps users schedule and manage appointments.
- Practises form validation, conditional statements, and date handling.

### Task 2: Job Application Tracker

**Folder:** `Task2-Job Application Tracker`

- Accepts job application details from the user.
- Tracks application information and status.
- Allows users to search for applications.
- Helps organise and monitor job application progress.
- Practises data management, searching, conditional statements, and JavaScript functions.

## Concepts Practiced

- Variables and data types
- Functions
- Conditional statements
- User input handling
- Form validation
- Date and time handling
- Searching and data management
- DOM manipulation
- Event handling

## Learning Outcome

These tasks help improve JavaScript programming and problem-solving skills by applying programming concepts to real-world scenarios involving appointment scheduling and job application management.
