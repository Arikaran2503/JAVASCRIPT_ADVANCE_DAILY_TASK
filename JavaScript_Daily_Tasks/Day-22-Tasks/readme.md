# Day 22 – JavaScript Advanced Tasks

## Project Overview
This project contains JavaScript practice programs focused on number pattern generation and electricity bill calculation. These tasks help improve logical thinking and problem-solving skills through practical exercises.

## Technologies Used
- HTML5
- JavaScript

## Folder Structure
```text
Day-22-Tasks/
├── Task1-Number-Pyramid/
└── Task2-Electricity-Bill-Calculator/
```

## Tasks

### 1. Number Pyramid
- Generates a pyramid pattern using numbers.
- Uses nested loops to arrange numbers in rows.
- Practices loops and pattern generation.

### 2. Electricity Bill Calculator
- Calculates the electricity bill based on units consumed.
- Uses conditional statements to determine applicable charges.
- Displays the calculated bill amount.

## Concepts Practiced
- JavaScript Variables and Functions
- For Loops and Nested Loops
- Conditional Statements
- User Input
- Arithmetic Operations
- DOM Manipulation

## Learning Outcome
Improved my understanding of JavaScript loops, number patterns, conditional logic, and mathematical calculations through practical programs.
