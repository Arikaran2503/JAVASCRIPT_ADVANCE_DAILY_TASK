# Day 27 – JavaScript Advanced Daily Tasks

## Project Overview

This project contains two JavaScript applications developed to practise programming concepts through real-world examples. The tasks focus on calculations, user input handling, conditional statements, and problem-solving using JavaScript.

The two applications are the **Bus Ticket Fare Calculator** and the **Monthly Budget Tracker**. Each task demonstrates how JavaScript can be used to process user input, perform calculations, and display results dynamically on a webpage.

## Technologies Used

- **HTML5** – Used to create the structure and input fields of the applications.
- **JavaScript** – Used to implement calculations, conditions, functions, and interactive features.

## Task 1: Bus Ticket Fare Calculator

### Description

The Bus Ticket Fare Calculator is a JavaScript application designed to calculate bus ticket fares based on the details entered by the user. It demonstrates how travel-related information can be processed to determine the applicable ticket cost.

### Features

- Accepts the required journey and passenger details through input fields.
- Processes the entered information using JavaScript.
- Calculates the ticket fare based on the conditions defined in the program.
- Displays the calculated fare to the user.
- Provides a simple and interactive interface for fare calculation.
- Helps users understand how ticket pricing can be handled through programming logic.

### Working Procedure

1. The user opens the Bus Ticket Fare Calculator.
2. The user enters the required journey or passenger information.
3. JavaScript retrieves the entered values.
4. The program checks the applicable conditions.
5. The ticket fare is calculated using the defined formula or rules.
6. The calculated result is displayed on the webpage.

### JavaScript Concepts Used

- Variables and data types
- Functions
- User input handling
- Conditional statements
- Arithmetic operations
- DOM manipulation
- Event handling

### Learning Outcome

This task improves my understanding of how to accept user input, apply conditions, perform calculations, and display results using JavaScript. It also helps me practise developing interactive applications based on everyday situations.

## Task 2: Monthly Budget Tracker

### Description

The Monthly Budget Tracker is a JavaScript application designed to help users calculate and monitor their monthly income and expenses. It demonstrates how financial information can be processed to understand spending and determine the remaining budget.

### Features

- Accepts monthly income and expense details from the user.
- Processes the entered values using JavaScript.
- Calculates total expenses based on the available expense information.
- Calculates the remaining balance after subtracting expenses from income.
- Displays the calculated budget information.
- Helps users understand their spending through simple calculations.
- Provides practical experience in developing an interactive budget management application.

### Working Procedure

1. The user opens the Monthly Budget Tracker.
2. The user enters the monthly income.
3. The user enters the required expense details.
4. JavaScript processes the entered income and expense values.
5. The application calculates the total expenses.
6. The remaining balance is calculated by subtracting total expenses from monthly income.
7. The calculated budget details are displayed on the webpage.

### Calculation

**Remaining Balance = Monthly Income − Total Expenses**

### JavaScript Concepts Used

- Variables and data types
- Functions
- Arrays and objects, if used in the implementation
- User input handling
- Arithmetic operations
- Conditional statements
- DOM manipulation
- Event handling
- Dynamic content updates

### Learning Outcome
