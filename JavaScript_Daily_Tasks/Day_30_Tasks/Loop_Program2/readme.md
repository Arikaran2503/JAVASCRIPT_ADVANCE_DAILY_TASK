# Loop Program 2 – JavaScript Daily Tasks

## 📌 Project Overview

Loop Program 2 is part of the Day 30 JavaScript daily practice tasks. This section contains four programming exercises focused on understanding loops, number patterns, and basic mathematical operations.

These tasks help improve logical thinking and provide practical experience in using JavaScript loops to solve different number-based problems.

## 📂 Tasks Included

### 1. Reverse Number Pattern

**Folder:** `Task1-Reverse-Number-Pattern`

This task focuses on printing numbers in a reverse pattern using JavaScript loops. It helps understand how loop conditions and decrement operations can be used to generate number patterns.

**Concepts Practiced:**
- `for` loop
- Reverse iteration
- Decrement operator
- Number patterns
- Loop conditions

### 2. Sum of 1 to N

**Folder:** `Task2-Sum-of-1-to-N`

This task calculates the sum of all natural numbers from 1 up to a given number (N). It uses a loop to add each number and display the final sum.

**Concepts Practiced:**
- `for` loop
- Variables
- Addition operator
- User input
- Accumulator logic
- Basic mathematical calculations

### 3. Print Even Numbers

**Folder:** `Task3-Print-Even-Numbers`

This task prints even numbers within a given range using JavaScript. It helps understand how to identify even numbers and display them using loops.

**Concepts Practiced:**
- `for` loop
- Modulus operator (`%`)
- Conditional statements
- Even number identification
- Increment operations

### 4. Print Odd Numbers

**Folder:** `Task4-Print-Odd-Numbers`

This task prints odd numbers within a given range. It uses loops and conditional checking to identify numbers that are not divisible by 2.

**Concepts Practiced:**
- `for` loop
- Modulus operator (`%`)
- Conditional statements
- Odd number identification
- Loop execution

## 🛠️ Technologies Used

- **HTML5** – Provides the structure for the task pages and input fields.
- **JavaScript** – Implements loops, conditions, calculations, and number patterns.
- **Browser** – Used to run and test the programs.

## 🎯 Learning Outcomes

By completing these tasks, the following skills can be improved:

- Understanding how JavaScript loops work.
- Printing number patterns using iteration.
- Performing mathematical calculations using loops.
- Identifying even and odd numbers.
- Using conditions inside loops.
- Understanding increment and decrement operations.
- Improving logical thinking and problem-solving skills.
