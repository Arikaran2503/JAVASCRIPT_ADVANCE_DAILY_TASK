# Day 29 – JavaScript Daily Tasks

## 📌 Project Overview

Day 29 contains two JavaScript practice tasks designed to improve programming logic and problem-solving skills through practical, real-world applications. The tasks focus on calculating coupon discounts and managing pet vaccination reminders using JavaScript.

These programs help strengthen the understanding of functions, conditional statements, user input, calculations, date handling, and basic validation.

## 📂 Tasks Included

### 1. Coupon Discount Calculator

**Folder:** `task1-Coupon-Discount-Calculator`

The Coupon Discount Calculator helps calculate the discount applied to a purchase using a coupon. It allows users to enter the purchase amount and coupon details, then calculates the discount and final payable amount based on the applicable conditions.

**Key Features:**
- Accepts the purchase amount and coupon details.
- Calculates the applicable discount.
- Determines the final amount after applying the discount.
- Uses conditional statements to check coupon eligibility.
- Displays the discount amount and final payable amount.

**Concepts Practiced:**
- JavaScript functions
- Variables and operators
- Conditional statements (`if`, `else`)
- User input and output
- Arithmetic calculations
- Basic input validation

### 2. Pet Vaccination Reminder

**Folder:** `task2-Pet-Vaccination-Reminder`

The Pet Vaccination Reminder is a JavaScript application designed to help track pet vaccination dates and remind users about upcoming or overdue vaccinations. It focuses on working with dates and checking vaccination schedules.

**Key Features:**
- Accepts pet and vaccination details.
- Records or processes vaccination dates.
- Checks upcoming and overdue vaccination schedules.
- Displays vaccination status based on the entered dates.
- Helps users keep track of their pets' vaccination schedules.

**Concepts Practiced:**
- JavaScript functions
- Variables and conditional statements
- Date handling
- String and date validation
- Comparison operators
- Logical operators
- Dynamic output based on conditions

## 🛠️ Technologies Used

- **HTML5** – Structures the web pages and input fields.
- **JavaScript** – Implements calculations, conditions, date handling, and application logic.
- **Browser** – Runs and tests the applications.

## 🎯 Learning Outcomes

By completing these tasks, the following skills can be improved:

- Applying JavaScript concepts to practical problems.
- Performing calculations based on user input.
- Using conditional statements to make decisions.
- Validating inputs before processing data.
- Working with dates and comparing vaccination schedules.
- Developing logical thinking and problem-solving skills.
- Building confidence in creating interactive JavaScript applications.
