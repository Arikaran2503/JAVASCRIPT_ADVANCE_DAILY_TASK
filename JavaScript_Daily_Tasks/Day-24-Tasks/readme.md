## Project Overview

This project contains two JavaScript applications that demonstrate how programming concepts can be used to calculate delivery charges and parking fees based on user input and specific conditions.

## Technologies Used

- HTML5
- JavaScript

## Tasks Included

### Task 1: Order Delivery Charge Calculator

**Folder:** `Task1-Order-Delivery-Charge-Calculator`

#### Description
The Order Delivery Charge Calculator calculates delivery charges based on the order details entered by the user.

#### Features
- Accepts order details from the user.
- Calculates the delivery charge based on the applicable conditions.
- Displays the delivery charge and relevant order cost details.
- Provides an interactive way to calculate delivery costs.

### Task 2: Parking Fee Calculator

**Folder:** `Task2-Parking-Fee-Calculator`

#### Description
The Parking Fee Calculator calculates parking charges based on the parking details entered by the user, such as parking duration.

#### Features
- Accepts parking details from the user.
- Calculates parking fees based on the applicable conditions.
- Displays the calculated parking fee.
- Helps users understand the cost of parking for the entered duration.
