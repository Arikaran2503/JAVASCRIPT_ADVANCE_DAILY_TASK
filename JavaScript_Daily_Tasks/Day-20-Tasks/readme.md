# Day 20 – Advanced JavaScript Tasks

## Project Overview
This project contains JavaScript practice tasks focused on password validation and shopping bill calculations. These programs help improve problem-solving skills and practical JavaScript knowledge.

## Technologies Used
- HTML5
- JavaScript

## Folder Structure
```text
Day-20-Tasks/
├── Task1-Password-Strength-Checker/
└── Task2-Shopping-Bill-Calculator/
```

## Tasks

### 1. Password Strength Checker
- Checks password strength based on specific validation rules.
- Validates password requirements such as length, numbers, and special characters.
- Displays the password strength based on the conditions satisfied.

### 2. Shopping Bill Calculator
- Calculates the shopping bill using product prices and quantities.
- Performs arithmetic operations to find the total amount.
- Displays the calculated bill based on user input.

## Concepts Practiced
- JavaScript Functions
- Variables and Operators
- Conditional Statements
- User Input and Validation
- DOM Manipulation
- Basic Mathematical Operations

## Learning Outcome
Improved my JavaScript problem-solving skills by creating interactive programs for password validation and shopping bill calculations.
