# Day 23 – JavaScript Advanced Daily Tasks

## Project Overview
This project contains JavaScript tasks focused on building interactive applications using user input, conditional statements, functions, and calculations.

## Technologies Used
- HTML5
- JavaScript

## Tasks Included

### Task 1: Mobile Recharge Plan
**Folder:** `Task1-Mobile-Recharge-Plan`

- Accepts mobile recharge details from the user.
- Processes the selected recharge plan.
- Displays the recharge details based on the selected plan.
- Practices conditional statements, user input, and JavaScript functions.

### Task 2: Hotel Room Booking
**Folder:** `Task2-Hotel-Room-Booking`

- Accepts hotel room booking details from the user.
- Processes room selection and booking information.
- Displays booking details based on the entered information.
- Practices conditional statements, calculations, and JavaScript functions.

## Concepts Practiced
- Variables and data types
- Functions
- Conditional statements
- User input handling
- Arithmetic operations
- DOM manipulation
- Event handling

## Learning Outcome
These tasks help improve JavaScript programming skills by applying basic concepts to practical, real-world scenarios.
