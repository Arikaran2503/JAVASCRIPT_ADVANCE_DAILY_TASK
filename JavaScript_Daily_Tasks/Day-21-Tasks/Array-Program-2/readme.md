# Day 21 – JavaScript Array Programs 2

## Project Overview
This project contains JavaScript array practice programs focused on sorting elements, counting even and odd numbers, and finding missing numbers. These tasks help improve array-handling and problem-solving skills.

## Technologies Used
- HTML5
- JavaScript

```text
    └── Task4-Missing-Number/
```

## Tasks

### 1. Ascending Order
- Sorts array elements from smallest to largest.
- Practices array sorting and number comparison.

### 2. Descending Order
- Sorts array elements from largest to smallest.
- Practices sorting and comparison operations.

### 3. Even and Odd Count
- Counts the even and odd numbers in an array.
- Uses loops and conditional statements to check each element.

### 4. Missing Number
- Finds the missing number in a sequence.
- Practices array traversal and mathematical operations.
