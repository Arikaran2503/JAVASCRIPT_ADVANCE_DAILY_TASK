# Day 25 – JavaScript Daily Tasks

## Project Overview

This project contains two JavaScript applications designed to practise calculations, user input handling, conditional statements, and functions through real-world scenarios.

## Technologies Used

- HTML5
- JavaScript

## Tasks Included

### Task 1: Movie Ticket Booking Calculator

**Folder:** `Task1-Movie Ticket Booking Calculator`

- Accepts movie ticket booking details from the user.
- Calculates the total ticket cost based on the number of tickets and ticket price.
- Displays the booking details and total amount.
- Helps practise arithmetic operations, conditional statements, and user input handling.

### Task 2: Employee Overtime Salary Calculator

**Folder:** `Task2-Employee Overtime Salary Calculator`

- Accepts employee salary and overtime details from the user.
- Calculates overtime pay based on the entered details.
- Calculates and displays the total salary, including overtime pay.
- Helps practise arithmetic operations, variables, functions, and conditional statements.

## Concepts Practiced

- Variables and data types
- Functions
- User input handling
- Conditional statements
- Arithmetic operations
- DOM manipulation
- Event handling

## Learning Outcome

These tasks improve JavaScript programming and problem-solving skills by applying calculations and programming concepts to practical scenarios such as movie ticket booking and employee salary calculation.
